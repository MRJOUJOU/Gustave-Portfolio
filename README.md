# Portfolio — John Gustave   AMOULE

Portfolio personnel — développeur web full stack, orienté cybersécurité.
React, Vite, Tailwind CSS v4, Framer Motion, AOS, Lucide, logos réels (simple-icons).

## Démarrer en local

```bash
npm install
npm run dev
```

Build de production :

```bash
npm run build
npm run preview
```
